# 60 Days of Python 

This repository is a personal archive of my 60 Days of Python challenge. 

Instead of just reading tutorials, I decided to learn by doing. I got completely locked in and built **42 unique, working projects** from scratch. This repo tracks my entire progression—starting from basic text games and variables, all the way up to data visualization engines and full-stack banking apps.

---

## Inside the Lab

To keep things clean, I organized all 42 projects into five numbered folders. This lets you track my day-to-day growth in chronological order:

* **`01_beginner_games_and_logic/`** – Where it all started. Pure Python logic, loops, conditionals, and terminal-based games.
* **`02_desktop_utilities/`** – Practical everyday tools, countdown timers, calculators, and building my first GUIs.
* **`03_web_and_automation/`** – Scripts that talk to the internet. Includes web scrapers, automated email senders, API integrations, and file organizers.
* **`04_data_visualization/`** – Projects focused on handling data and rendering custom charts (Bar, Line, Pie, and Scatter plots).
* **`05_banking_and_finance/`** – Advanced projects. Complex financial simulators, calculators, chatbots, and apps with deep backend logic.

---

## 🛠️ What I Mastered
* **Core Python:** Object-Oriented Programming (OOP), complex data structures, and clean coding standards.
* **Automation:** Writing scripts to control the local file system, scrape web data, and automate repetitive workflows.
* **Data Handling:** Plotting metrics and managing state variables in financial logic apps.
